INFOLINKY STATIC WEBSITE — GITHUB PAGES DEPLOYMENT

1. Extract this ZIP file on your computer.
2. Open your GitHub repository: https://github.com/infolinky/infolinky
3. Upload the CONTENTS of this folder to the repository root (not the containing folder).
4. Commit the upload.
5. Open repository Settings > Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish. Your site should be:
   https://infolinky.github.io/infolinky/

IMPORTANT:
- This is a static HTML/CSS/JavaScript website; it does not require Node.js or a build command.
- Contact and advertising forms open the visitor's email application. They do not store submissions on a server.
- Analytics, Search Console verification and AdSense are intentionally not activated. Add only your genuine IDs after setup/approval.
- Marketplace links currently lead to official provider websites, not affiliate tracking links. Replace with your approved affiliate URLs when available and retain visible disclosure.
- Review privacy/cookie policies if you activate analytics, ads, mailing-list forms or other third-party services.
- All included images are in assets/images/.
